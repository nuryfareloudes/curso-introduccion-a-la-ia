## 1. Obtener el material del curso

```bash
git clone [URL del repositorio]
```

## 2. Actualizar el material cada semana

```bash
git pull
```

Usa la plantilla de [`recursos/plantillas/repositorio-estudiante/`](../recursos/plantillas/repositorio-estudiante/) para crear tu propio repositorio, donde subirás el código de las Actividades Evaluativas.
